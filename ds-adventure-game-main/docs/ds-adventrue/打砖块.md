# 打砖块

玩法：底部一根板子，球往上弹打掉上面的砖，板子左右移动接球，球掉了就少一条命。砖打掉得分，全部打完过关。砖有不同颜色不同血量。

可扩充玩法和功能（随便列）：多球、板子变长变短道具、球加速减速、穿透球、激光发射、砖块掉落道具（加命、变长、分裂）、关卡编辑、boss砖（打很多下还反击）、砖块会往下压、挡板有弹性区、球带拖尾、连击加分、重力改变、风力、磁铁吸球、可破坏的墙、隐藏砖、限时、双人分屏、墙壁反弹角度随击球点变、球分裂、激光塔、存档、排行榜、关卡包、特殊砖（炸一片、变彩色）、联网对战互相扔道具、挡板带凹槽、球有质量、砖块移动、能量条放大招、背景音乐节奏影响速度、残局、连消倍率、掉落护盾、冰砖冻板。
