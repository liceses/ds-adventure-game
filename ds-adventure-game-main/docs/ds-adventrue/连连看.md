# 连连看

玩法：一片格子里铺满成对的小图标，点两个相同的图标，如果它们之间能用不超过两个拐弯的线连起来（线不能穿过别的图标，且不出边界），这两个就消掉。把所有对子消完就赢。有时间限制或者提示次数。

可扩充玩法和功能（杂乱）：不同难度棋盘、重排（死局时洗牌）、提示（高亮一对）、道具（炸弹消任意、穿越消隔一个、时空静止暂停倒计时）、计时、连击、分数、皮肤包（动物、水果、汉字、emoji）、关卡、局部遮挡（雾）、3D层叠、动态出现新块、双人分屏比谁消得多、限时冲分、连消加成、背景故事、音效、排行榜、关卡编辑、随机图案、图案会移动（每隔几秒挪一格）、障碍格不可消、连锁消除动画、联网对战互相加干扰块、残局、撤销、自动求解演示、难度曲线、主题包、盲消（只露边缘）、连击倍率、图案成对但不同色也算、磁吸相邻、计时加速、关卡BOSS（限定步数）。
