# 贪吃蛇

玩法：一条蛇在画面里爬，吃豆子就变长，撞墙或者撞自己就死。用方向键控制上下左右，不能掉头（比如正在往右不能马上往左）。豆子随机出现，吃了加分，蛇越来越长越来越难。可以做成穿墙模式（从一边出去从另一边进来）或者不穿墙。速度能慢慢变快。

可扩充的玩法和功能（杂乱列一下，不用都做）：穿墙与否、加速道具、减速陷阱、多条蛇抢豆、障碍物墙、豆子分大小（大的加更多分但蛇涨更快）、限时模式、迷宫地图、AI蛇跟玩家抢、双人分屏对战、过关解锁更长初始长度、记录最高分排行榜、蛇皮肤换色、吃特定豆触发反向控制几秒、食物有保质期过期消失、特殊食物让蛇缩短、关卡里预设障碍地形、联网两人同屏抢食、摇杆或触屏支持、蛇头带磁铁吸近处豆、食物成串出现、加速带、断尾机制、毒豆扣命、复活一次。
