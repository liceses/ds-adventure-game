# 扫雷

玩法：一片格子，里面藏了若干地雷，左键翻开格子，如果翻到雷就炸了，没雷就显示周围八格里有几颗雷的数字。右键插旗标雷。把所有不是雷的格子都翻开就赢。根据数字推理雷的位置。可以选初级（9x9，10雷）、中级、高级。

可扩充玩法和功能（随便想，不整理）：自定义雷数、首点必开空（第一次点保证安全且展开一片）、问号标记、计时和步数、连开（点到数字且周围旗数对就自动开周围）、彩色数字、不同雷型（链雷、触发雷）、残局存档、榜单、手机长按、题目分享（把某个局面编码成字符串发给别人挑战）、局部提示、撤销一步、自动标雷辅助、排行榜按时间、关卡编辑器、地雷会移动（每隔几秒挪一格）、双人竞赛同图比谁先清、盲扫（看不到数字只靠记忆）、迷宫式雷区、雷区有水流推动标记、标记错误惩罚、连锁爆炸、安全区奖励、夜视模式、声音定位雷。
