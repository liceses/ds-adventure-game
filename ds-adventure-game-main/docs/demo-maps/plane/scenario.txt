# ============================================================
#  飞机大战小游戏 —— 验收用演示地图（事件 ID: plane）
#
#  用法：启动播放器 → 菜单「打开地图文件夹…」→ 选中本目录
#        进入 Start 场景会自动把小游戏嵌入主舞台中央，
#        点标题栏的【← 返回剧情】即可回到剧情。
#
#  验收要点（需求 F5）：
#    · 战机在下方，方向键 / WASD 移动
#    · 空格 / J 射击（按住连续发射）
#    · 击落 20 架通关，击落 1 架 10 分
#    · 3 条命，被撞或中弹扣命
#    · 拾取护盾道具后 3 秒内免伤
#    · 敌机每 3 秒生成 1 架起，每秒递减 0.1 秒，下限 0.5 秒
# ============================================================
