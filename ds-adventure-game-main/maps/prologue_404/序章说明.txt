《序章 · 404之夜》演示地图说明
================================

这是一个用「地图编辑器（Studio）」搭出来的剧情地图，用来演示：
  ① 基本逻辑分支对话（选项 → 变量 → 条件 → 不同内容）
  ② 背景与人物立绘全部用简洁图形代替（不需要任何图片素材）
  ③ 不需要任何音频素材

打开方式
--------
· 编辑器：文件 → 打开地图文件夹 → 选择本目录（prologue_404），或用 Ctrl+R 在播放器里试玩
· 播放器：把 config.ini 的 map.folder 指向本目录后启动

场景一览（共 14 幕）
--------------------
  序01_灯会      第一幕·发布会（点对话框逐段推进；右上角「下一幕 ▸」可跳过）
  序02_演讲      快 / 轻 / 白给
  序03_打结      思维链打了个结 + 庆功曲
  序04_断灯      九盏齐灭 + 【服务器繁忙，请稍后再试】
  序05_过秤      柜台升起，九片鳞逐片离去
  序06_灯官      看不见的膜 +「灯未点齐，人不放行」
  序07_白水      千问酱的白水 +「等。顺便数灯。」
  序08_求救      「九片鳞，九个泉眼。一片，一片，替我点回来。」
  序09_抉择      ★ 三选一（逻辑分支主演示）
  序09A_热回声 / 序09B_稳回声 / 序09C_影回声   三条枝
  序10_星空      四种「回响」只显示一种（条件分支）
  序11_数灯      ★ 计数 + 大小比较（点亮数 >= N → 第 N 盏灯亮）
  序12_待续      存档 / 打开说明文件 / 定位文件 / 从头再来 / 退出游戏

逻辑分支是怎么做的
------------------
1) 选项 → 变量：每个选项的槽里用 @plugin(inc) 给「热度 / 专注 / 混乱」+1，
   并用 @plugin(set) 把「选过热 / 选过稳 / 选过影」置为 true。
2) 动态跳转：选项把目标场景名写进变量「下一场」，再用
       slot = 选热 | goto |  | @var(下一场)
   跳过去 —— 目标场景名是运行期算出来的，不是写死的。
3) 条件内容：选项同时把序10_星空 里四个「回响」变体的 visible 设好，
   所以到了那一幕只会显示与你的选择对应的那一段；都没选过时显示兜底段（else 分支）。
4) 计数与比较：序11_数灯 每点一次
       @plugin(inc) 点亮数 +1  →  @plugin(min) 压到上限 9
       @plugin(ge)  点亮数 >= N  →  set 亮灯11_N visible = 结果
   点到 9 时「灯全亮」变 true，GLM 娘那段台词才出现。

「简洁图形」是怎么做的
----------------------
· 背景：一个铺满 1280×720 的 text 节点，样式里写渐变
      style = -fx-background-color: linear-gradient(to bottom, #1b1030, #2d1a3f 55%, #3a2140); -fx-text-fill: rgba(255,255,255,0.09);
    中心那行大字就是「幕名水印」。
· 立绘：一个圆角卡片 text 节点，内容写 emoji + 角色名 + 表情 id，样式里写底色/描边
      style = -fx-background-color: linear-gradient(...); -fx-background-radius: 20; -fx-border-color: rgba(126,196,255,0.7); -fx-border-radius: 20;
· 灯、柜台、膜同理（灯 = 🕯/💡 方块，柜台 = 带描边的方块，膜 = 一条细渐变）。

自制系统插件（本图用到的）
--------------------------
  @plugin(quit)             退出游戏（关闭播放器窗口；编辑器预览只关预览窗）
  @plugin(open) | 序章说明.txt   用系统默认程序打开本文件（路径相对地图文件夹）
  @plugin(reveal) | 序章说明.txt 在资源管理器中定位本文件
