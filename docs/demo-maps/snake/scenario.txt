# ============================================================
#  贪吃蛇小游戏 —— 验收用演示地图（事件 ID: snake）
#
#  用法：启动播放器 → 菜单「打开地图文件夹…」→ 选中本目录
#        进入 Start 场景会自动把小游戏嵌入主舞台中央，
#        点标题栏的【← 返回剧情】即可回到剧情。
#
#  验收要点（需求 F4）：
#    · 区域 10×10 格，蛇初始长度 3
#    · 每吃 1 豆 分数 +1；累计吃 97 颗通关
#    · 速度 = 初速 + 0.01 × 已玩秒数
#    · 方向键 / WASD 转向，允许 180° 反向（反向撞到自身即失败）
# ============================================================
