# 用现有插件实现功能（不要改源码）—— 协作说明

> 面向：剧情/演出组、外部插件作者
> 一句话：**要什么效果，先查「槽 + 内置插件」能不能做；能做的绝不改引擎源码。**
> 实在没有的能力，写一个**外部插件**（`SlotPlugin`）挂进来，也不要动 `ReaderView` 这些引擎文件。

---

## 一、先说清一件事：地图里的「点击音」不是插件实现的

`maps/story` 点击推进对话时有「咔」的一声，但**地图脚本里找不到任何音频槽** —— 因为它是**引擎内置的 UI 音效**：

| 音效 id | 什么时候响 | 需要的文件 |
|---|---|---|
| `se_click` | 点击推进对话（对话面板被点击） | `assets/sounds/se_click.wav` |
| `se_hover` | 鼠标悬停在选项按钮上 | `assets/sounds/se_hover.wav` |
| `se_select` | 点击确认选项/按钮 | `assets/sounds/se_select.wav` |

- 代码位置：`com.studio.reader.ReaderView#playUiSound(String)`（约 L1096），调用点 L1123 / L1128 / L1162；
- 声音从 `assets/sounds/<id>.wav` 找（地图目录优先，其次 classpath `src/main/resources/`）；
- **文件不存在就静默跳过**，不会报错 —— 所以想「有点击音」，把 `se_click.wav` 放进
  `src/main/resources/assets/sounds/`（或地图的 `assets/sounds/`）即可，**一行脚本都不用写**；
- 想要别的音色：**直接替换这个 wav 文件**（保持文件名），不要改代码。

> 这就是"看起来像用了插件、其实没有"的原因。下面讲**通用做法**：凡是能这样"放文件就生效"或"写一行槽就生效"的，都别去动源码。

---

## 二、能力的三个层次（按优先级用）

1. **放素材就生效**（最省事）：UI 音效 `se_click/se_hover/se_select`、`bg` 背景图、`cast` 立绘表情等；
2. **写一行槽**（最常用）：`slot = 信号名 | 动作 | 目标 | 参数 | 附加参数`，
   动作可以是 `goto / set / log / toggle / emit`，也可以是 `@plugin(插件id)`；
3. **写外部插件**（引擎真没有才做）：实现 `com.studio.plugin.SlotPlugin`，扔进 `plugins/`，在 `plugins/plugins.ini` 注册。

**不要做**：改 `ReaderView` / `SignalBus` / `PluginRuntime` 等引擎源码来加功能。那样会让所有地图和队友都被绑住，
而且下次同步/合并必然冲突（这个仓库里已经踩过：谁改了引擎，别人拉下来就编不过）。

---

## 三、怎么查现在有哪些插件（三步）

1. **编辑器**：节点属性窗口 / 场景属性窗口的「**＋ 插入插件槽**」下拉框 —— 列的是全部可用插件
   （ID、中文名、别名、用法提示），选中即插入一条槽模板；
2. **本文件第三节的速查表**（内置插件全家桶，随程序发行、无需注册）；
3. **外部插件**：`plugins/plugins.ini` 注册的 + `plugins/*.jar`、`plugins/classes/` 里的类。

`@plugin(...)` 的参数就是槽里的**目标 / 参数 / 附加参数**三段（`@param(名)` 取信号参数）。
写法示例：

```ini
slot = 场景进入 | @plugin(audio) | loop | assets/sounds/theme.wav | bgm
slot = 点灯     | @plugin(audio) | play | assets/sounds/se_bell.wav  | se
```

## 四、内置插件速查（按用途）

| 用途 | 插件 id（别名） | 典型用法 |
|---|---|---|
| **音频/音效** | `audio`（音效/声音） | `play` 播一次 / `loop` 循环 / `stop` / `pause` / `resume` / `volume`；末位是通道名（`bgm`/`se`/自定义） |
| 视频 | `video` | 播放/停止/暂停/音量 |
| 舞台：立绘 / 背景 / 特效 | `cast`、`bg`、`fx`（抖动/闪白/心跳） | `cast` 切立绘表情与位置，`bg` 换背景，`fx` 抗震/闪白 |
| 流程 | `select`（如果/三目）、`after`（延时）、`every`（定时）、`stoptimer`（停定时）、`switch`（节点信号/槽开关） | `select` 写回变量做分支；`after/every` 定时发信号 |
| 逻辑 | `and or xor not gt lt ge le eq ne` | 组合条件、比较大小 |
| 数学 | `add sub(减法) mul div mod pow min max abs round floor ceil neg set` | 计数器、钳制、写变量 |
| 文本 | `concat upper lower trim len sub replace pad repeat split num money percent duration` | 拼显示文本（配合 `set ... text`） |
| 随机 | `rand` | 随机数/概率 |
| 存档 | `slots hasslot delslot copyslot readslot writeslot saveinfo` | 存档槽查询与操作 |
| 对话框 | `confirm`、`input` | 二次确认、玩家输入 |
| 时间 | `clock` | 取系统时间（做时钟） |
| 系统/桌面 | `quit`、`open`、`pick`、`reveal`、`fullscreen`、`clipboard`、`notify`、`screenshot` | 退出、打开文件、全屏、剪贴板、系统通知 |
| 列表/JSON | `list`、`json` | 数组式数据存取 |
| 网络 | `http`、`llm` | 取接口/大模型返回（写回变量） |
| 调试 | `debug`、`trace`、`dump` | 打印变量、追踪信号、导出状态 |

> 记不住没关系：**在编辑器下拉框里选**，或看插件自己的提示（每个插件都有 `usage()` 说明）。

## 五、三个可直接照抄的配方

### 配方 A：对话「点击音」（推荐）

**什么都不用写。** 只要这三个文件在位，引擎自动响：

```
src/main/resources/assets/sounds/se_click.wav    ← 点击推进对话
src/main/resources/assets/sounds/se_hover.wav    ← 选项悬停
src/main/resources/assets/sounds/se_select.wav   ← 选项确认
```

想换音色就**换同名的 wav**；想关掉就删文件（或把文件重命名）。

### 配方 B：给某个按钮/对话框加**自定义**音效（不依赖内置 UI 音）

```ini
[序01_灯会]
# 1) 声明信号：鼠标点击某节点时发（节点 id = 点灯按钮11）
signal = 点灯 | mouse | click

# 2) 槽里播音效：play 播一次，末位是通道名（同一个通道重复播会打断上一次）
slot = 点灯 | @plugin(audio) | play | assets/sounds/se_bell.wav | se
# 想同时改别的效果，就再写几条同信号的槽（按书写顺序执行）：
slot = 点灯 | set | 亮灯11_1 | visible | value=true
```

要点：
- **信号**决定"什么时候"（`mouse|click`、`mouse|release`、`key|F`、场景自动信号 `场景进入/场景离开/上一个场景离开`）；
- **槽**决定"做什么"，一行做一件事，**按书写顺序依次执行**；
- 参数里可以用表达式：`@var(变量)`、`@int(3)`、`@bool(true)`、`@param(名)`（取信号参数）。

### 配方 C：BGM 与场景切换

```ini
[序01_灯会]
slot = 场景进入 | @plugin(audio) | loop | assets/sounds/theme.wav | bgm
slot = 场景离开 | @plugin(audio) | stop |  | bgm          # 换幕停掉，避免叠播
slot = 场景离开 | @plugin(stoptimer) | 每秒               # 定时器同理要收尾
```

## 六、反模式清单（评审会打回的做法）

| ❌ 不要 | ✅ 应该 |
|---|---|
| 改 `ReaderView` / `SignalBus` / 引擎类来加功能 | 用槽 + 内置插件；不够就写外部 `SlotPlugin` |
| 把音频写进节点属性（`audio = …`） | 音频属性已废除，统一用 `@plugin(audio)` 或内置 UI 音效 |
| 写死绝对路径（`F:\…\a.wav`） | 用相对路径 `assets/sounds/a.wav`（地图目录优先，classpath 兜底） |
| 同一个场景里重复声明同名信号 | 一个信号只声明一次，多条槽挂同一个信号 |
| 用插件做"引擎本来就会做"的事（如点击音再写一遍） | 先查内置能力：UI 音效、`bg`/`cast`/`fx`、自动信号 |
| 在槽里堆逻辑、把地图写成代码 | 复杂逻辑放 `logic/` 里的 `LogicHandler`，或用 `@plugin(select/set/…)` 组合 |

## 七、真要加新能力：写外部插件（而不是改源码）

```java
package com.example;

import com.studio.plugin.SlotPlugin;
import com.studio.plugin.PluginContext;

/** 最小槽插件：@plugin(hello) | 目标 | 参数 */
public class HelloPlugin implements SlotPlugin {
    @Override public String id() { return "hello"; }
    @Override public String usage() { return "@plugin(hello) | 谁 | 说什么   → 在日志里打招呼"; }
    @Override public String[] execute(PluginContext ctx, String[] args) {
        String who = args.length > 0 ? args[0] : "世界";
        String what = args.length > 1 ? args[1] : "你好";
        ctx.log("[hello] " + who + "：" + what);
        return args;              // 返回值会按 @var(...) 位置写回变量
    }
    @Override public void onDetach() { /* 停线程/停 Timeline，避免退出后还在跑 */ }
}
```

接入步骤：
1. 编译成 class 放进 `plugins/classes/`（或打成 jar 放 `plugins/`）；
2. 在 `plugins/plugins.ini` 加一行：`hello = com.example.HelloPlugin`；
3. 地图里就能用：`slot = 入场 | @plugin(hello) | ds娘 | 我来了`；
4. 自检：编辑器插件下拉框能看到 `hello`；「关于 → 插件目录」里没有"未实现 SlotPlugin"的告警。

约束：插件里**不要**直接改引擎内部对象；能拿到的能力都在 `PluginContext`（日志、变量、节点属性、弹提示、发信号等）。

## 八、改完怎么自检

1. **编辑器**里 `Ctrl+R`（在播放器中测试）跑一遍，看演出是否符合预期；
2. **控制台**（按 `` ` ``，或地图 `[option] console = true`）：
   `vars` 看变量、`emit <信号名>` 手动触发那条槽、`env` 看引擎信息 —— 用来定位"信号没发"还是"槽没跑"；
3. **日志**里不该出现 `未知动作`、`没有参数`、`找不到槽插件` 之类告警；
4. `mvnw.cmd -B test` 全绿（别把源码改动混进剧情改动里）。

## 九、给对话框 / 文本框加背景图（不用改源码）

**方案 A（推荐：纯地图、可移植、跟着地图目录走）** —— 在对话框**下面**叠一个图片节点，把对话框底设成透明：

```ini
{ type = bg  id = 对话框底图  x = 70  y = 516  width = 1140  height = 178
  path = assets/ui/dialog_panel.png }

{ type = dialog  id = 对话框  x = 70  y = 516  width = 1140  height = 178
  text = <<< 台词… >>>
  style = -fx-background-color: transparent; -fx-border-color: transparent; }
```

- 原理：引擎 `buildDialog()` 会把你写的 `style` **拼在内置底样式之后**再应用，同一段内联样式**后写的覆盖前面的** → 透明底生效（地图里现有的「全屏点击层」就是这么写的）；
- **节点书写顺序 = 层级**（后写的在上层），所以底图节点必须写在对话框**之前**；
- `type = textbox` / `text` 同样支持 `style`，做法一模一样。

**方案 B：直接写在节点样式上**

```ini
style = -fx-background-image: url("/assets/ui/dialog_panel.png"); -fx-background-size: 100% 100%; -fx-background-repeat: no-repeat;
```

⚠️ 内联 `url()` **不走地图目录解析**（那是 `FxAssets` 的规则），只能写 classpath 绝对路径（`/assets/…` → `src/main/resources/assets/…`）或 `file:` 绝对路径（不可移植）。想「跟地图一起走」请用方案 A。

**面板图不想被拉伸变形 → 九宫格（9-slice）**

```ini
style = -fx-border-image-source: url("/assets/ui/panel_9slice.png");
        -fx-border-image-slice: 24;
        -fx-border-image-width: 24;
        -fx-border-image-repeat: stretch;
```

圆角/描边/角标保持原样，只有中间区域随尺寸拉伸；素材按 24px 切边即可。
