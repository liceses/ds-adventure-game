# 飞机大战

玩法：玩家的飞机在屏幕下方，自动或者按键发射子弹打从上面下来的敌机，敌机也往下掉或者射击。躲子弹别被撞，打掉敌机得分，被打中就掉血或者死。可以捡道具（子弹变多、炸弹清屏）。关卡越往后敌机越多越快。

可扩充玩法和功能（想到哪写哪）：多种敌机（直冲、横移、射击、自爆）、boss、道具（散弹、激光、护盾、加速、回血、磁铁吸分）、弹幕、僚机、血量护盾、连击、关卡、背景滚动、流星、陨石、可破坏掩体、飞机升级（机型解锁）、技能（核弹清屏）、移动平台、二段跳、蓄力射击、联机双人同机、排行榜、存档、难度曲线、随机生成波次、隐藏敌机、彩蛋、音效、震屏、慢动作、武器合成、敌机AI、地形障碍、限时生存模式、Boss多阶段、克隆机、网战PK比分、护盾反弹、子弹穿透、能量槽大招、天气影响弹道、友军NPC、掉落零件组装。
