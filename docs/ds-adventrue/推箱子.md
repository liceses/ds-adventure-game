# 推箱子

玩法：一个仓库管理员把箱子推到指定目标点。人能推不能拉，一次推一个，箱子抵墙或者抵别的箱子就推不动。把所有箱子都推到目标点就过关。地图是格子，有墙、地板、箱子、目标点、人。

可扩充玩法和功能（杂乱）：多关卡、关卡编辑器、步数和推数统计、撤销、回放、最佳步数星级、箱子有重量（两个推不动）、冰面（推一下滑到底）、传送门、可拉动的绳子机制、双人对推、移动的目标点、会消失的地板、计时赛、机关（踩开关开门）、谜题随机生成、存档、提示系统（高亮一步解法）、3D视角、箱子上带图案要对准方向、暗关卡（看不到全图）、联网两人合作推同一图、陷阱格、连锁反应、箱子里有球滚出来、推错可拉回一次、磁铁方块相吸、多色箱子对应多色目标、箱子叠高、限时关卡、残局、自动求解演示。
