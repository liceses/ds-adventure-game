## 三、技术路线（游戏组已定，向各位同步）

**不是再造一套引擎。** 路线是：

> **写一个编译器**：`剧本/*.txt` →（编译）→ 标准地图文件
> **＋补 6 处小能力**（合计约 350 行）

这样可以**完整复用**已有的渲染引擎、Studio 编辑器、存档系统和小游戏宿主；编译器产物 **Studio 能打开检查、播放器能直接玩**。

> **说明**：交接文档给的是行式剧本 DSL（`@scene` / `@enter` / `角色:` / `narr:` / `*choice` / `@flag` / `@if` / `@label` / `goto` / `@minigame` / `@save` / `@ending`），与游戏内部地图格式不同。
> **剧本仍是唯一源，地图是编译产物**（不入库，随剧本重新生成）。

### 3.1 映射关系（简版）

| 剧本写法 | 编译为 |
|---|---|
| `@label ch1_win` | 一个场景 |
| `@scene id bg:X bgm:Y title:Z` | 背景节点 + 音乐节点（素材缺失自动占位） |
| `@enter ds cute center` | 立绘节点（左/中/右固定位；**同角色再次 `@enter` = 换表情，不叠图**） |
| `@exit ds` | 该立绘退场 |
| `ds: 台词` | 名牌 + 对话框（打字机） |
| `narr: 文本` | 无名牌对话（**不参与立绘逻辑**） |
| `st: 文本` | 全屏横幅（4 种演出模板） |
| `*choice` + `> 文本 \| flag X +1 \| goto L` | 一组选项按钮 + 状态写入 + 跳转 |
| `@flag` / `@if` / `goto` | 变量运算 + 条件跳转 |
| `@save` | 到达即自动存档（支持同章多槽） |
| `@ending id` | 结局标记并停止 |
| `@minigame …` | 小游戏触发 + 胜负结果路由 |

## 四、需要各位配合的事项

### 4.1 剧情组

1. **继续用现有 DSL 写剧本，不要改格式**；`@label` 保持全局唯一（当前 87 个、零冲突，很好）
2. **请拍板 4 个待决项**（交接文档 §9，逐条给结论即可）：

| # | 待决 | 影响 | 建议 |
|---|---|---|---|
| 1 | §9-7b：终章 `with:name` 引用了 `name`，但全剧从未赋值（第 3 章写的是 `name_light` / `name_bubble`） | 终章传参为空 | **游戏组在编译期把 `name_*` 映射为 `name`**，剧本不动 |
| 2 | §9-7c：第 4 / 7 / 8 章的策略选项（`steady` / `bloom` / `bold`）没传进小游戏 | 玩法不受策略影响 | 首版**不传**，后续按需扩 |
| 3 | §9-7：9 个 flag 无下游消费者（`bloom` / `bold` / `steady` / `name_light` / `name_bubble` / `honest` / `resolve` / `tempo` / `trust`） | 现在写了不影响任何剧情 | **保留存取**（引擎不丢弃）；是否接结局细分由剧情组定 |
| 4 | §9-5：第 7 章 3 处 `@save` 语义 | 存档覆盖规则 | 按「进沼前 = 主档 / 失败点 = 自动档 / 澄清后 = 覆盖主档」实现 |

3. 后续若要改剧本：**只改台词、不动结构**（结构改动会同时影响编译器，请提前说一声）

### 4.2 美术 / 素材组

1. **背景命名**：对齐 `bg_<场景id>.png`（14 个 id 见交接文档 §7.2），**或**给一张「现有文件 → 场景 id」映射表
2. **立绘命名**：统一成 `<角色id>_<表情>.png` 扁平式（如 `amiya_firm.png`），**或**给映射表（例如 `sprites/ds/normal.png` → `ds_normal.png`）
3. **素材入库**：目前素材都没进版本库，队友拉代码跑不了。请确认由谁、以什么范围入库（建议先入序章 + 第 1 章要用的）
4. 优先级：**序章 + 第 1 章**所需背景 / 立绘先补齐（最小可玩切片演示用）

## 六、里程碑与验收

### M1 最小切片（先交付，用于演示与中期检查）

> 序章 → 第 1 章 → 选项 → **贪吃蛇** → 胜 / 负双路 → 回剧情 → `pieces == 1` → 续接台词

覆盖需求验收项 **P0-3 剧情推进 / P0-4 选项分支 / P0-5 小游戏切入 / P0-6 返回不丢进度**。

### M2 全量

> 11 章贯通 + 5 结局路由（`chaos>=3 → temp`、`pieces==9 → true`、`6~8 → local`、`bad_collapse`、`busy`）+ 三种调度模式 + 双版本台词切换

### 验收方法（照交接文档 §8）

- 第 1 章选「直接咬蛇尾」→ 确认走 `ch1_chaos` 且 `chaos+1`
- 贪吃蛇胜负双路 → 均回剧情 → `pieces == 1`
- 五子棋（第 9 章）故意输 3 次 → 三档嘲讽依次出现、flag 不丢
- 扫雷（第 7 章）失败 → `bad_collapse` 结局 → 读档回流
- 改存档 `chaos=3` → 终章进 `temp`；`pieces=9` → `true`
